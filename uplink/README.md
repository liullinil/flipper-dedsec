# DedSec Uplink — монитор ПК, Codex и Claude + карманный cmd.exe на Flipper Zero

Две части:

| Часть | Где | Что делает |
|---|---|---|
| Приложение Flipper | `apps/dedsec_uplink` → `/ext/apps/Bluetooth/dedsec_uplink.fap` | Свой BLE-сервис (без PIN), показывает данные, вибрирует, принимает ввод команд |
| Компаньон ПК | `uplink/dedsec_uplink.pyw` | Значок в трее: собирает нагрузку и состояние агентов, выполняет команды, Bluetooth |

## Экраны (вкладки ◀ ▶)

- **SYS** — CPU, RAM, сеть, диск. В режиме «полоски» сеть и диск масштабируются автоматически
  (по скользящему максимуму), плюс график CPU. В режиме «текст» — точные скорости up/dn, rd/wr.
- **CDX** — сессии Codex (CLI `codex --profile router` и приложение), подагенты строками под корнем.
- **CLD** — сессии Claude Code (CLI и вкладка Code в Claude Desktop).
- **CMD** — карманный терминал: пишешь команду на Flipper → она выполняется на ПК → вывод и код
  возврата возвращаются на экран. Каталог сохраняется между командами (как настоящий cmd.exe).

Набор и порядок вкладок настраивается (можно скрыть ненужные).

## Управление

- **◀ ▶** — вкладки. **▲ ▼** — выбор сессии / прокрутка консоли. **OK** — детали сессии; на CMD — ввод команды.
- **OK (долго)** — настройки. **Назад** — назад / выход; на CMD во время выполнения — отмена команды.
- Когда сессия ждёт тебя, Flipper вибрирует, мигает LED и показывает баннер:
  `!! APPROVAL NEEDED !!` (вопрос/подтверждение) или `>> YOUR TURN <<` (ход закончен). OK открывает сессию.
- Когда консоль ответила — короткая вибрация (настраивается отдельно).

## Настройки (в приложении, долгий OK)

Всё сохраняется в `/ext/apps_data/dedsec_uplink/.uplink.settings`:

- **Vibration** — вибрация вкл/выкл (работает даже в stealth-режиме Unleashed).
- **Vibrate on cmd reply** — вибрировать, когда консоль ответила.
- **LED alerts** — подсветка RGB-светодиодом на событиях.
- **Wake screen on alert** — будить экран на событиях.
- **Indicators** — Bars (полоски) или Text (текст) для SYS.
- **Theme** — Normal или Inverted (светлое на тёмном).
- **Font size** — Normal или Large (крупнее, меньше строк).
- **Tab 1..4** — какой экран на каждой вкладке (или Off, чтобы скрыть) — так меняется порядок вкладок.

## Карманный cmd.exe

На вкладке CMD жми **OK**, набери команду экранной клавиатурой, нажми **save**. Команда уходит на ПК,
выполняется в постоянном `cmd.exe` (каталог и часть окружения сохраняются между командами), вывод
построчно возвращается на Flipper, в конце — `[exit N]` и короткая вибрация. **Назад** во время
выполнения — отмена (перезапуск шелла).

- Первая буква команды автоматически делается заглавной (это особенность клавиатуры Flipper).
  В Windows команды и большинство ключей регистронезависимы, так что `Ver`, `Dir`, `Ipconfig` работают.
- Вывод режется по строкам (до 400 на команду), команда дольше 2 минут автоматически останавливается.
- По умолчанию шелл — `cmd.exe`. PowerShell можно включить в `config.json` (`"shell": "powershell"`).

**Безопасность.** Канал BLE без сопряжения: кто угодно в радиусе Bluetooth, зная протокол, в теории мог
бы слать команды. Поэтому: удалённый шелл можно выключить в трее («Allow remote shell»), каждая команда
пишется в лог, вывод ограничен. Если не пользуешься CMD — выключи его в меню трея.

## Компаньон на ПК

Значок черепа в капюшоне в трее. Кольцо: зелёное — связь есть, жёлтое — ищет, серое — пауза, красное — ошибка.
Меню (правый клик):

- **Pause uplink** — отключить/подключить BLE.
- **Allow remote shell (cmd)** — разрешить выполнение команд с Flipper (по умолчанию включено).
- **Start with Windows** — автозапуск при входе (ключ `HKCU\…\Run`).
- **Open log** / **Quit**.

### Установка

Python 3.9+ и пакеты:

```bash
python -m pip install "bleak==0.22.3" pystray psutil pillow
```

`bleak` 1.x не работает на Python 3.9.0, поэтому зафиксирована 0.22.3.

```bash
pythonw D:\src\Flipper\uplink\dedsec_uplink.pyw
```

Режимы: `--console` (лог в консоль), `--dump` (один кадр без Bluetooth),
`--install-autostart` / `--uninstall-autostart`. Лог: `%LOCALAPPDATA%\DedSecUplink\uplink.log`.
Второй экземпляр не запускается.

## Точный статус Claude через хуки

Без хуков состояние Claude берётся эвристикой из логов. Точные переходы (ждёт тебя / твой ход / работает)
дают хуки Claude Code:

```bash
python D:\src\Flipper\uplink\install_claude_hooks.py          # поставить (сливается с твоим settings.json)
python D:\src\Flipper\uplink\install_claude_hooks.py --remove # убрать
```

Добавляются хуки `Notification`, `Stop`, `SubagentStop`, `UserPromptSubmit`, которые запускают
`uplink_hook.py` и пишут события в `%LOCALAPPDATA%\DedSecUplink\claude_events.jsonl`. Компаньон читает их
и показывает точный статус. Существующие настройки сохраняются, рядом кладётся бэкап `settings.json.bak-*`.
После установки перезапусти сессии Claude Code (или `/hooks`), чтобы хуки подхватились.

Codex подобных хуков не имеет — его состояние по-прежнему берётся из `~/.codex/sessions/*.jsonl`
(в профиле `router` стоит `approval_policy = never`, поэтому «ждёт тебя» там значит конец хода или вопрос).

## Протокол

PC → Flipper (характеристика RX `de5ec001-…`):

```
H|host                                   S|cpu|ram|disk|rd|wr|up|dn|used|total
L|X|count   (X=Codex, C=Claude)          I|X|idx|key|state|done|total|age|attn|name|detail
O|seq|текст (строка вывода команды)       X|seq|код (команда завершилась)
W|cwd       (каталог шелла)               B (ПК отключается)
```

Flipper → PC (характеристика TX `de5ec002-…`, notify):

```
C|seq|команда    K|seq (отмена)
```

`state`: `W` работает, `A` ждёт ответа/подтверждения, `I` твой ход, `S` простой. `attn` растёт при каждом
переходе в ожидание — по его росту Flipper вибрирует.

## Сборка приложения Flipper

```bash
cd D:\src\Flipper\apps\dedsec_uplink
ufbt            # сборка -> dist/dedsec_uplink.fap
ufbt launch     # залить (USB) и запустить
```

Прошивка Unleashed `unlshd-093c`, API 88.9. Связь без сопряжения, поэтому событие «подключено» прошивкой
не приходит — связь считается живой, пока идут данные. При выходе восстанавливается стандартный
Bluetooth-профиль (для телефона).
