# DedSec Uplink (Flipper app)

Monitor of PC load, Codex and Claude sessions over BLE. Full description, protocol and the PC companion: [../../uplink/README.md](../../uplink/README.md).

```bash
ufbt launch   # install to /ext/apps/Bluetooth and start
```
